# Esboços das telas novas (08/11/2026)

Só visual, com **dados fictícios**, para aprovar antes de programar os blocos A e B do plano único. Abrir os HTML no navegador (mesmas cores e fontes das páginas). Cada esboço tem uma caixa amarela "Para decidir no esboço".

| Arquivo | Pacote | Tela |
|---|---|---|
| `1-ficha-ordem.html` | E5 | Ficha da ordem (painel lateral, aberto em qualquer página) |
| `2-busca-ctrlk.html` | E5 | Busca Ctrl K por índice (ordem, lote, LP, catálogo, equipamento) |
| `3-planner.html` | E6 / E8 | Iniciativas › Ações: quadro, detalhe, histórico e tempos |
| `4-minha-fila.html` | E10a | Portal › Minha fila |
| `5-reuniao-diaria.html` | E10b | Portal › Reunião diária |
| `6-equipamentos.html` | E11 | Equipamentos: ficha, falhas (histórico), OS, TAGs, estrutura AM/TPM |
